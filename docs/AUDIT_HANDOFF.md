# Проверка данных: первый безопасный пакет

## Запуск из корня проекта
```
py -m unittest discover -s tests -p test_data_quality.py -v
py -m unitka.data_quality --backup out/backups/pre_audit_20261114.db
```
При повторе выберите новое имя копии. Отчёт: out/data_quality/report.json и checks.csv.
Коды: 0 без предупреждений; 1 предупреждения; 2 ошибки/непроверенные запросы.
Модуль не вызывает API, не мигрирует базу, не меняет формулы и цены.
can_reprice всегда false, это не проверка допуска репрайсера.
Результаты и резервные копии коммерчески чувствительны: не добавлять в Git.

## Проверено автоматически
Пять тестов: неизменность исходного файла при проверке; отсутствие создания
несуществующей базы; запрет записи; копирование и запрет перезаписи; активный WAL.
Среда проверки: Python 3.12, искусственная база, не Windows пользователя.

## Ограничения диагностики
Регистрирует агрегаты и кандидаты проблем, а не доказывает правильность финансов.
Отсутствующие таблицы требуют проверки требований. Повтор номера отчёта не основание
для удаления. На запрос установлен лимит времени; прерывание означает не проверено.
Историческая себестоимость проверяется отдельно от текущей методики unit_core.

## Вместе после коммита
1. Запустить тесты и диагностику на копии; разобрать отчёт и длительность.
2. Восстановить backup в отдельном каталоге и сверить контрольные суммы отчётов.
3. Утвердить себестоимость: последняя или на дату продажи (сейчас unit_core — последняя).
4. Проверить частичный закрытый месяц: unit_core выбирает месячные строки целиком.
5. Сверить продажу, поддержку, возврат, количество, знаки и округление; затем месяц и банк.
6. Согласовать формулы ABC/XYZ с unit_core; не объяснять всё баллами без проверки.
7. Проверить полноту API, дубли по подтверждённым ключам, чужие SKU и журнал загрузок.
8. Только затем исправлять финансовые формулы и допуск репрайсера; испытать dry-run.
9. Доработать ИИ-отчёты, модель по умолчанию, интерфейс и тестовые вопросы.
10. Проверить новую механику Ozon по документам, Google, Ollama, Excel и VPS отдельно.
