# Модуль 3: Управление рекламой

## Цель
Оптимизация рекламных кампаний для максимизации ROAS.

## Процесс

### 3.1 Аудит кампаний
- Текущие кампании: `/v1/advertising/campaigns`
- Статистика: `/v1/advertising/stats`
- Метрики: CTR, CPC, CR, ROAS, ДРР

### 3.2 Отбор локомотивов
Критерии:
- Статус карточки: «готова к рекламе"
- Остаток: >50 шт
- Продажи: >10 шт/неделю
- Маржа: >30%
- Рейтинг: >4.5

### 3.3 Стратегия
- Типы кампаний: поиск + карточка
- Бюджеты: по категориям
- Ставки: приоритеты по SKU

### 3.4 A/B тесты
- Тест заголовков
- Тест фото
- Тест цен
- Тест описаний

### 3.5 Оптимизация
- Автопауза неэффективных (ROAS <2)
- Корректировка ставок
- Масштабирование успешных

## Метрики
- Расходы на рекламу (руб)
- CTR (%)
- CPC (руб)
- CR (%)
- ROAS
- ДРР (%)

## Отчёты
- Ежедневный: расходы и результаты
- Еженедельный: оптимизация
- Ежемесячный: итоги и план
