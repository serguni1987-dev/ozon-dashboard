# Модуль 4: Финансы и юнит-экономика

## Цель
Расчёт прибыльности каждого SKU и общей рентабельности бизнеса.

## Процесс

### 4.1 Юнит-экономика по SKU
Формула:

Прибыль = Цена продажи − Себестоимость − Комиссия Ozon − Логистика − Реклама − Налоги

Маржа (%) = (Прибыль / Цена продажи) × 100

### 4.2 Выгрузка данных
- Цены: `/v2/pricing/info`
- Продажи: `/v1/reporting/getReport`
- Финансы: `/v1/finance/cash-flow-statement`
- Реклама: `/v1/advertising/stats`

### 4.3 Дашборд финансов
- Выручка (руб)
- Расходы по статьям (руб)
- Прибыль (руб)
- Маржа (%)
- Рентабельность (%)

### 4.4 Выявление убыточных
- SKU с отрицательной маржой
- Товары с низким ROAS
- Рекомендации: поднять цену / убрать / заменить

### 4.5 План по прибыли
- Целевая маржа по категории
- План по чистому доходу
- Оптимизация расходов

## Метрики
- Выручка (руб)
- Себестоимость (руб)
- Комиссия Ozon (руб)
- Логистика (руб)
- Реклама (руб)
- Налоги (руб)
- Прибыль (руб)

- Еженедельный: маржа по SKU
- Ежемесячный: полный P&L
