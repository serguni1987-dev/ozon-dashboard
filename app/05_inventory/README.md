# Модуль 5: Склад и логистика

## Цель
Оптимизация остатков, избегание out-of-stock, минимизация логистических расходов.

## Процесс

### 5.1 Выгрузка данных
- Остатки: `/v2/analytics/stocks`
- Склады: `/v1/warehouse`

### 5.2 Анализ остатков
- Текущие остатки по складам
- Товары в пути
- Оборачиваемость (дни)

### 5.3 Прогноз закупок
Формула:

Прогноз = (Продажи за 30 дней / 30) × Срок поставки × Коэффициент запаса

### 5.4 Оптимизация склада
- Распределение по складам Ozon
- Минимизация логистики
- Избегание out-of-stock

## Метрики
- Остаток (шт)
- Оборачиваемость (дни)
- Out-of-stock (%)
- Логистические расходы (руб)

## Отчёты
- Ежедневный: критические остатки
- Еженедельный: прогноз закупок
- Ежемесячный: оборачиваемость
