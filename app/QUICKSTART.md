## 5 шагов для запуска

### Шаг 1: GitHub (5 минут)

```bash
# Создайте репозиторий на GitHub
# Скопируйте туда все файлы из папки ozon-marketplace-management
git clone https://github.com/yourusername/ozon-marketplace-management.git
cd ozon-marketplace-management
git add .
git commit -m "Initial commit"
git push origin main
```

### Шаг 2: Конфигурация (5 минут)

```bash
# Скопируйте шаблон
cp config_template.json config.json

# Откройте config.json и вставьте:
# - Client ID от Ozon API
# - API Key от Ozon API
```

**Где взять Ozon API ключи:**
1. Зайдите в Ozon Seller
2. Профиль → Настройки → API
3. Создайте новый ключ
4. Скопируйте Client ID и API Key

### Шаг 3: Google Таблицы (10 минут)

1. Создайте новую таблицу: `Ozon Marketplace Management`
2. Создайте 8 листов:
   - Товары и карточки
   - Продажи и аналитика
   - Реклама и кампании
   - Финансы и юнит-экономика
   - Склад и остатки
   - Отзывы и рейтинг
   - Конкуренты
   - Сводный дашборд

3. Скопируйте `spreadsheet_id` из URL таблицы
4. Вставьте в `config.json`

### Шаг 4: Установка зависимостей (5 минут)

```bash
pip install requests pandas openpyxl
```

### Шаг 5: Тестовая выгрузка (10 минут)

```bash
cd scripts
python ozon_api_export.py
```

Проверьте файлы в `assets/exports/` — должно быть 9 CSV файлов.
