## 8 модулей системы

| № | Модуль | Назначение | Ключевые метрики |
|---|--------|------------|------------------|
| 1 | Карточки | Аудит и улучшение | CTR, конверсия, рейтинг |
| 2 | Продажи | Аналитика и прогноз | Выручка, штуки, динамика |
| 3 | Реклама | Кампании и ROAS | ROAS, ДРР, CPC |
| 4 | Финансы | Прибыль и маржа | Маржа %, прибыль, ROI |
| 5 | Склад | Остатки и закупки | Оборачиваемость, out-of-stock |
| 6 | Отзывы | Репутация | Рейтинг, негатив %, скорость |
| 7 | Конкуренты | Мониторинг | Цена, позиция, доля |
| 8 | Отчёты | Дашборды | Все метрики в одном месте |

## Следующие шаги

### Прямо сейчас (30 минут)

1. Создайте GitHub репозиторий
2. Скопируйте файлы проекта
3. Настройте `config.json` с API ключами
4. Запустите тестовую выгрузку

### Этап 1: Инфраструктура (2–3 дня)

- [ ] GitHub репозиторий создан
- [ ] Google Таблица с 8 листами готова
- [ ] Notion база знаний создана
- [ ] API ключи получены

### Этап 2: Выгрузка (3–4 дня)

- [ ] Скрипт выгрузки работает
- [ ] Данные импортированы в Таблицы
- [ ] Автоматизация настроена

### Этап 3: Пилот (5–7 дней)

- [ ] Аудит 10–20 SKU проведён
- [ ] Карточки улучшены
- [ ] Статус «готова к рекламе" присвоен

## Контакты и доступы

Для запуска вам понадобятся:

- **Ozon API:** Client ID + API Key
- **Google API:** credentials.json + spreadsheet_id
- **GitHub:** аккаунт для репозитория
- **Notion:** аккаунт для базы знаний
