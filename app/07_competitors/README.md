# Модуль 7: Конкурентный анализ

## Цель
Мониторинг конкурентов, позиционирование, оптимизация цен.

## Процесс

### 7.1 Мониторинг конкурентов
- Цены на аналогичные SKU
- Их карточки (фото, описание)
- Их отзывы и рейтинг
- Позиции в выдаче

### 7.2 Позиционирование
- Уникальные преимущества
- Отстройка от конкурентов
- Ценовое позиционирование

### 7.3 Рекомендации
- Где поднять цену
- Где снизить цену
- Где усилить карточку

## Метрики
- Средняя цена по рынку (руб)
- Наша цена (руб)
- Разница (%)
- Позиция в выдаче

## Отчёты
- Еженедельный: мониторинг цен
- Ежемесячный: полный анализ конкурентов
