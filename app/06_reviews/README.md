# Модуль 6: Отзывы и репутация

## Цель
Увеличение рейтинга, отработка негатива, снижение возвратов.

## Процесс

### 6.1 Выгрузка данных
- Отзывы: `/v1/reviews`
- Вопросы: `/v1/questions`
- Рейтинг: `/v1/rating`

### 6.2 Анализ отзывов
- Средний рейтинг по SKU
- Частые претензии
- Причины возвратов
- Слова покупателей

### 6.3 Отработка негатива
- Шаблоны ответов
- Скорость ответа (<24 часов)
- Решение проблем

### 6.4 Стимулирование отзывов
- Программа лояльности
- Follow-up письма
- Бонусы за отзывы

## Метрики
- Средний рейтинг
- Количество отзывов
- Процент негатива (%)
- Скорость ответа (часы)

## Отчёты
- Ежедневный: новые отзывы
- Еженедельный: анализ рейтинга
- Ежемесячный: динамика репутации
