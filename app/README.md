# Ozon Marketplace Management

Полная система управления маркетплейсом Ozon: карточки, продажи, реклама, финансы, склад, отзывы.

## Структура

- `01_product_cards` — управление карточками товаров
- `02_sales_analytics` — аналитика продаж
- `03_advertising` — управление рекламой
- `04_finance` — финансы и юнит-экономика
- `05_inventory` — склад и логистика
- `06_reviews` — отзывы и репутация
- `07_competitors` — конкурентный анализ
- `08_reporting` — отчётность и дашборды
- `scripts` — скрипты для выгрузки и автоматизации
- `templates` — шаблоны отчётов и документов
- `docs` — документация и регламенты
- `assets` — скриншоты, фото, экспорты

## Быстрый старт

1. Настройте доступы к Ozon API
2. Запустите скрипт выгрузки данных
3. Импортируйте данные в Google Таблицы
4. Начните аудит карточек
