# Модуль 2: Аналитика продаж

## Цель
Анализ динамики продаж, выявление трендов и проблемных SKU.

## Процесс

### 2.1 Выгрузка данных
- Отчёт по продажам: `/v1/reporting/getReport`
- Аналитика по товарам: `/v1/analytics/data`
- Период: последние 30/60/90 дней

### 2.2 Дашборд продаж
- Продажи по дням/неделям/месяцам
- Выручка в рублях
- Продажи в штуках
- Динамика роста/падения (%)

### 2.3 ABC-анализ
- A: топ-20% SKU по продажам (80% выручки)
- B: средние 30% SKU (15% выручки)
- C: низкие 50% SKU (5% выручки)

### 2.4 Выявление проблем
- Падающие продажи (>20% снижение)
- Товары без продаж (30+ дней)
- Сезонные спады
- Out-of-stock

### 2.5 Прогнозирование
- Прогноз на следующий месяц
- План по закупкам
- Рекомендации по ассортименту

## Метрики
- Выручка (руб)
- Продажи (шт)
- Средний чек (руб)
- Динамика (%)
- Доля категории (%)

## Отчёты
- Ежедневный: продажи за вчера
- Еженедельный: итоги недели
- Ежемесячный: полный анализ
